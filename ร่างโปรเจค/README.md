# CareMate Bangkok
### ระบบจัดการบริการผู้ช่วยและพยาบาลพาผู้สูงอายุไปโรงพยาบาล
**โครงงานปริญญานิพนธ์ (Senior Project)**

---

## 1. ภาพรวมระบบ (Project Overview)
CareMate Bangkok เป็นระบบเว็บแอปพลิเคชันสำหรับอำนวยความสะดวกในการจองบุคลากรทางการแพทย์ (พยาบาลวิชาชีพ RN และผู้ช่วยพยาบาล CG) เพื่อพาผู้สูงอายุหรือผู้ป่วยไปรับการตรวจรักษาที่โรงพยาบาล โดยมีจุดเด่นคือระบบเงินพักคนกลาง (Escrow) เพื่อความปลอดภัยในการชำระเงินของผู้รับบริการ และระบบบันทึกสัญญาณชีพเพื่อติดตามอาการระหว่างเดินทาง

---

## 2. ฟังก์ชันการทำงานตามสิทธิ์ผู้ใช้ (System Modules)

### 2.1 ผู้รับบริการ / ญาติผู้ป่วย (Patient & Family)
* คัดเลือกบุคลากรตามตำแหน่ง (RN/CG), ค่าบริการ และรีวิว
* ส่งคำขอจองบริการ พร้อมระบุโรงพยาบาล อาการ และอุปกรณ์จำเป็น
* ชำระเงินผ่าน QR Code พร้อมเพย์ เข้าสู่ระบบเงินพักคนกลาง (Escrow)
* ติดตามสถานะงาน ดูบันทึกสัญญาณชีพ (Vitals) และส่งรีวิวประเมินการบริการ

### 2.2 บุคลากรทางการแพทย์ (Caregiver & Nurse)
* รับงานและตรวจสอบรายละเอียดภารกิจ สถานที่นัดหมาย และข้อมูลผู้ป่วย
* บันทึกค่าสัญญาณชีพ (ความดัน, ชีพจร, ระดับออกซิเจน) ระหว่างปฏิบัติงาน
* ตรวจสอบยอดเงินส่วนแบ่งในกระเป๋าเงิน (85%) และส่งคำขอเบิกเงินเข้าบัญชีธนาคาร

### 2.3 ผู้ดูแลระบบ (Admin)
* Dashboard สรุปภาพรวมสถานะงานและยอดเงินหมุนเวียน
* ตรวจสอบเอกสารคุณวุฒิและประวัติอาชญากรรมของบุคลากรก่อนอนุมัติ
* ตรวจสอบสลิปโอนเงินของผู้รับบริการและอนุมัติการล็อกเงิน Escrow
* ตรวจสอบและอนุมัติการโอนเงินค่าตอบแทนให้บุคลากร พร้อมแนบหลักฐานสลิป
* สรุปรายงานการเงิน รายได้แพลตฟอร์ม (15%) และส่งออกไฟล์ CSV/Excel
* ตั้งค่าระบบและทดสอบการเชื่อมต่อส่งอีเมล (SMTP / OTP)

## 3. สถาปัตยกรรมและเครื่องมือที่ใช้ (Tech Stack)

* **ส่วนติดต่อผู้ใช้ (Frontend):** HTML5, Tailwind CSS, JavaScript (Vanilla ES6+)
* **ระบบหลังบ้าน (Backend):** Python (FastAPI), Uvicorn ASGI Server
* **ฐานข้อมูล (Database):** SQLite (`caremate.db`)
* **การยืนยันตัวตนและการแจ้งเตือน:** Session Management, SMTP Email (OTP)

---

## 4. ขั้นตอนการติดตั้งและรันระบบ (Setup & Running)

### 4.1 ติดตั้งไลบรารีที่จำเป็น
```bash
pip install fastapi uvicorn pydantic requests
```

### 4.2 เริ่มต้นการทำงานของเซิร์ฟเวอร์
```bash
python care.py
```
*ระบบจะเปิดให้บริการที่พอร์ต `http://localhost:8000`*

### 4.3 เข้าใช้งานระบบ
เปิดเว็บเบราว์เซอร์แล้วพิมพ์ URL:
```text
http://localhost:8000
```
