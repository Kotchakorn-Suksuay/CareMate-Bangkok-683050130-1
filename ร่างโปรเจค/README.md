# 🏥 CareMate Bangkok — Medical Escort & Healthcare Concierge Platform

> **แพลตฟอร์มดิจิทัลสำหรับการจองบริการพาผู้สูงอายุและผู้ป่วยไปโรงพยาบาลโดยบุคลากรทางการแพทย์**  
> พร้อมระบบคุ้มครองเงินพักคนกลาง (Escrow Safety) และศูนย์บริหารจัดการครบวงจร

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ (Key Features)

### 1. 👥 ระบบสำหรับผู้รับบริการและญาติผู้ป่วย (Patient & Family Portal)
- **ค้นหาและคัดเลือกผู้ดูแล:** เลือกบุคลากรตามความเชี่ยวชาญ (พยาบาลวิชาชีพ RN / ผู้ช่วยพยาบาล CG) พร้อมแสดงอัตราค่าบริการและคะแนนรีวิว
- **ระบบจองบริการและระบุข้อมูลผู้ป่วย:** ระบุโรงพยาบาลปลายทาง แผนกการรักษา อาการเบื้องต้น และอุปกรณ์ที่จำเป็น
- **การชำระเงินปลอดภัยด้วย PromptPay QR:** สแกนชำระเงินผ่านระบบเงินพักคนกลาง (CareMate Escrow) เงินจะไม่ถูกโอนให้ผู้ดูแลจนกว่าภารกิจจะเสร็จสิ้นสมบูรณ์
- **ระบบติดตามสถานะและการประเมิน:** ตรวจสอบตำแหน่งการเดินทาง ดูบันทึกสัญญาณชีพ (Vitals) และให้คะแนนรีวิวหลังจบงาน

### 2. 🩺 ระบบสำหรับบุคลากรทางการแพทย์ (Caregiver & Nurse Portal)
- **ตรวจสอบตารางงานที่ได้รับมอบหมาย:** ดูรายละเอียดภารกิจ สถานที่นัดหมาย และข้อมูลผู้ป่วย
- **บันทึกข้อมูลสัญญาณชีพ (Vital Signs):** ค่าวัดความดันโลหิต ชีพจร ระดับออกซิเจน และน้ำตาลในเลือดระหว่างปฏิบัติภารกิจ
- **กระเป๋าเงินดิจิทัลและขอเบิกเงิน (Wallet & Payouts):** จัดสรรรายได้ส่วนแบ่ง 85% ตรวจสอบประวัติการเงิน ยื่นคำขอถอนเงินเข้าบัญชีธนาคาร พร้อมตรวจสอบสลิปโอนเงิน

### 3. 🛡️ ศูนย์ควบคุมและบริหารจัดการสำหรับผู้ดูแลระบบ (Admin Portal)
- **ศูนย์ควบคุมภาพรวม (Dashboard):** ติดตามสถิติการจอง ยอดเงิน Escrow และสถานะกำลังพล
- **ตรวจสอบคุณวุฒิและประวัติ (KYC & Criminal Record Audit):** ตรวจสอบใบประกอบวิชาชีพและประวัติอาชญากรรมก่อนอนุมัติเข้าสู่ระบบ
- **การจัดการเงินพักคนกลาง (Escrow Audit):** ตรวจสอบสลิปโอนเงินของลูกค้าและกดยืนยันล็อกเงินพัก
- **การอนุมัติเบิกจ่ายรายได้ (Caregiver Payouts):** ตรวจสอบคำขอถอนเงินและแนบหลักฐานสลิปการโอนเงินจริง
- **รายงานสรุปทางการเงิน (Financial & Usage Report):** สรุปยอดธุรกรรมรวม (GMV), รายได้แพลตฟอร์ม 15%, ค่าตอบแทนบุคลากร 85%, กราฟแนวโน้มรายเดือน และการส่งออกรายงาน Excel/CSV (UTF-8)
- **ระบบแจ้งเตือนทางอีเมล (SMTP Configuration):** จัดการรหัส OTP ยืนยันตัวตนและการแจ้งเตือนอัตโนมัติ

## 🛠️ เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)

- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6+), Phosphor Icons, Leaflet Maps
- **Backend:** Python, FastAPI, Uvicorn ASGI Server, Pydantic, WebSockets
- **Database:** SQLite (Relational Database)
- **Authentication & Security:** Session-based Authentication, Role-based Access Control (Admin, Nurse, Caregiver, User), OTP Verification via SMTP

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. การติดตั้งไลบรารีที่จำเป็น (Prerequisites)
ตรวจสอบว่าติดตั้ง Python 3.9+ แล้ว จากนั้นรันคำสั่ง:
```bash
pip install fastapi uvicorn pydantic requests
```

### 2. การเปิดเซิร์ฟเวอร์ Backend
เปิด Command Prompt หรือ Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
python care.py
```
*ระบบจะเปิดเซิร์ฟเวอร์ที่ `http://127.0.0.1:8000` พร้อมสร้างฐานข้อมูลเริ่มต้นโดยอัตโนมัติ*

### 3. การเข้าใช้งานเว็บไซต์ (Frontend)
เปิดเว็บเบราว์เซอร์ (Google Chrome หรือ Microsoft Edge) แล้วเข้าไปที่:
```text
http://127.0.0.1:8000
```
*(หรือเปิดไฟล์ `index.html` บนเบราว์เซอร์โดยตรง)*
